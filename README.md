# 밸런스 & 라이어

친구들과 각자 폰으로 하는 **밸런스 게임**과 **라이어 게임** 웹앱이에요. 주루마블의 두 미니게임을 따로 떼어 만들었고, 같은 방에 들어온 모든 폰이 Firebase Realtime Database 로 실시간 동기화돼요.

## 1. Firebase 준비

주루마블과 같은 `juru-marvel` 프로젝트를 쓰고, 데이터 위치만 `blRooms` 로 나눴어요. 콘솔 → Realtime Database → 규칙 탭에 아래 내용을 붙여넣고 **게시**하세요 (`database.rules.json` 과 같음). 주루마블(`rooms`), 주루윷놀이(`yutRooms`), 밸런스 & 라이어(`blRooms`)를 모두 열어 두는 규칙이에요.

```json
{
  "rules": {
    "rooms": { ".read": true, ".write": true },
    "yutRooms": { ".read": true, ".write": true },
    "blRooms": { ".read": true, ".write": true }
  }
}
```

## 2. 배포 (GitHub → Vercel)

이 폴더를 GitHub 저장소에 올리고 Vercel 에서 Import 하면 끝이에요. Framework 는 Vite 로 자동 인식되고 Build Command `npm run build`, Output `dist` 가 기본값이에요.

## 3. 실행 (내 컴퓨터)

```bash
npm install
npm run dev
```

`http://localhost:5173/?demo=1` 로 열면 서버 없이 한 기기에서 가짜 참가자 3명과 함께 미리 볼 수 있어요 (한 기기로 모든 사람의 투표를 대신 눌러요).

## 4. 진행 방식

이름을 정하고 방을 만들거나(비밀번호 선택), 홈 화면의 열린 방 목록을 눌러 들어가요. 초대 링크로도 들어올 수 있어요. 방에 들어오면 게임 메뉴가 나오고, **방장**이 게임을 고르고 결과 공개·다음 판을 눌러요. 투표와 키워드 확인은 각자 자기 폰에서 해요. 방장은 👑 로 넘길 수 있고, 방장이 나가면 접속 중인 사람에게 자동으로 넘어가요.

- **밸런스 게임 (2명부터)**: A vs B 주제가 나오면 각자 하나를 골라요. 누가 투표했는지만 보이고 무엇을 골랐는지는 공개 전까지 숨겨요. 접속 중인 모두가 투표하면 방장이 결과를 공개하고, 3·2·1 뒤 **소수 의견이 마셔요**. 동점이면 다른 주제로 다시 투표하고, 만장일치면 룰렛(50%: 다 같이 마셔 / 아무도 안 마셔)을 돌려요. 주제는 200개이고 한 번 나온 주제는 다 돌 때까지 다시 안 나와요. 투표 중에 🔄 다른 주제로 바꿀 수 있어요.
- **라이어 게임 (3명부터, 워드 울프 방식)**: 방장이 카테고리(음식·영화·나라·기업·브랜드·스포츠·전자기기·앱·사람)를 고르면 지금 방에 있는 모두에게 키워드가 배정되고, 한 명만 비슷하지만 다른 키워드를 받아요 (본인도 모름). 각자 폰에서 탭해 확인하고, 정해진 순서대로 설명한 뒤 투표해요. 설명 순서의 첫 사람은 판마다 한 칸씩 돌아가요. 결과는 3·2·1 뒤 다른 키워드를 받은 사람과 득표 수를 보여주고(키워드는 공개 안 함), 득표 칸을 누르면 누가 찍었는지 펼쳐져요. **라이어를 맞힌 사람은 안 마시고, 못 맞힌 사람이 마셔요.** 게임 도중에 들어온 사람은 그 판은 구경하고 다음 판부터 같이 해요.

각 판이 끝나면 방장이 "한 판 더"(라이어는 같은 카테고리로, 또는 카테고리 바꾸기)나 "메뉴로"를 골라요. 진행 중에도 🏠 메뉴로 그만둘 수 있어요.

상단 🍺 버튼은 오늘의 술고래(벌칙으로 마실 때 자동으로 센 잔 수 순위)이고, 방장은 여기서 잔 수를 초기화할 수 있어요. ≡ 버튼은 게임 로그예요. 효과음은 `src/sound.js` 에서 `SOUND_ENABLED = true` 로 켤 수 있어요 (기본 꺼짐).

방은 참가자가 없거나, 모두 접속이 끊긴 채 10분이 지나거나, 1시간 동안 아무 활동이 없거나, 만든 지 24시간이 지나면 자동으로 정리돼요.

## 5. 데모 주소 옵션 (테스트용)

| 옵션 | 뜻 |
| --- | --- |
| `?demo=1` | 서버 없이 한 기기에서 모든 참가자를 조작 |
| `&fbarr=1` | Firebase 처럼 배열/빈 값을 바꿔서 돌려줌 (동기화 테스트) |
| `&debug=1` | 진단 패널 (방 상태) |
| `&pid=abc` | 같은 브라우저에서 다른 참가자로 열기 (실서버 2인 테스트) |

## 6. 구조

`src/room.js` 방·참가자·밸런스·라이어 진행(DB 읽기·쓰기), `src/App.jsx` 화면, `src/styles.css`, `src/db.js` Firebase/데모 저장소, `src/firebase.js` Firebase 설정, `src/game/balance.js` 밸런스 주제 200개, `src/game/liar.js` 라이어 키워드 7개 카테고리.
